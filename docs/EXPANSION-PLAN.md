### ما هو غائب تمامًا ❌

| العنصر | الأثر على التوسّع |
|---|---|
| **طبقة i18n** | لا توجد. `BaseLayout.astro:22` → `<html lang={SITE.lang} dir="rtl">` مثبّت. اللغة العربية والاتجاه RTL مُدمَجان في الكود |
| **نصوص مُستخرَجة** | كل النصوص عربية مكتوبة داخل المكوّنات و**داخل المحرك نفسه** |
| **مسارات لغوية** | لا `/en/`، لا `/id/`. بنية المسارات أحادية اللغة |
| **hreflang متعدد** | `Seo.astro:39-40` يُخرج `hreflang="ar"` و `x-default` فقط — يشيران لنفس الرابط |
| **ملف فقهي لكل دولة** | لا يوجد. النصاب والمذهب ثابتان عالميًا |

> قبل إضافة أي دولة. البناء على الوضع الحالي دولة بعد دولة سيولّد دَينًا تقنيًا مضاعفًا.

## 2. العوائق التقنية الحرجة قبل أي توسّع

### 2.1 🔴 أسعار الصرف مُثبّتة في الكود وقديمة — **الخطر الأول**

`src/lib/zakat.ts:19-30` يحتوي أسعار صرف ثابتة. قارنتُها بأسعار السوق الحقيقية الآن:

| العملة | القيمة في الكود | القيمة الحقيقية (2026-08-09) | الفرق |
|---|---|---|---|
| EGP | 49.00 | **49.79** | −1.6% |
| MAD | 9.90 | **9.31** | **+6.3%** ⚠️ |
| KWD | 0.307 | 0.309 | −0.6% |
| OMR | 0.385 | 0.384 | +0.3% |
| SAR / AED / QAR / JOD / BHD | مربوطة بالدولار | مطابقة | ✅ |

**لماذا هذا خطر وجودي وليس تفصيلة؟**

المحرك يحوّل كل شيء للدولار داخليًا ثم يقارنه بالنصاب:

```ts
// zakat.ts:73-80
export function zakatMoney(localTotal, cur, p) {
  const usd = toUSD(localTotal, cur);          // ← يستخدم السعر المثبّت
  return usd >= cashNisabUSD(p) ? usd * RATE : 0;
}
```

فخطأ 6.3% في سعر الدرهم المغربي **يُزيح عتبة النصاب 6.3%**. المستخدم الذي يملك مالًا
عند حدّ النصاب قد يُخبَر "لا زكاة عليك" وهو في الحقيقة وجبت عليه — أو العكس.
هذا خطأ **شرعي**، لا خطأ عرض. والعملات المستهدفة للتوسّع (IDR، TRY، PKR، NGN)
عملات **عالية التقلّب**: الليرة التركية والروبية والنايرا تتحرك عشرات النسب سنويًا.

**الحل:** جدول أسعار يُحدَّث في وقت البناء (build-time) + تحديث حيّ في المتصفح
مع تراجع آمن، بنفس نمط `fetchLivePrices()` الموجود أصلًا للذهب والفضة.

### 2.2 🔴 المحرك يُرجع نصوصًا عربية — يقتل i18n من الجذر

```ts
// zakat.ts:126-146
export function zakatLivestock(type, count): string {
  if (n < 40) return "لا زكاة (النصاب 40)";
  if (n <= 120) return "شاة واحدة";
  ...
  return "راجع جدول الإبل التفصيلي";   // ← وأيضًا: الجدول غير مكتمل!
}
```

المحرك النقيّ يجب أن يُرجع **بيانات**، لا **نصوصًا للعرض**. المطلوب:

```ts
// الشكل المستهدف
{ due: true, animal: "sheep", count: 1, ruleId: "sheep.40_120" }
```

ثم تُترجَم `ruleId` في طبقة العرض. بدون هذا، كل لغة جديدة تعني تعديل المحرك —
وهو ما سيكسر الاختبارات في كل مرة. **وأيضًا:** جدول الإبل ناقص فعليًا فوق 46 رأسًا
(يُرجع نصًا يقول "راجع جدول الإبل التفصيلي") — هذا نقص وظيفي، لا نقص ترجمة.

كذلك `fmt()` مثبّتة على `"ar-EG-u-nu-latn"`:

```ts
// zakat.ts:44
return new Intl.NumberFormat("ar-EG-u-nu-latn", {...})
```

الإندونيسي يكتب `1.234.567,89` والأمريكي `1,234,567.89`. لا بد من تمرير الـ locale.

### 2.3 🔴 زكاة الفطر: ثابت عالمي واحد = خطأ في كل دولة

```ts
// zakat.ts:11
export const FITR_PER_PERSON_USD = 8;
```

زكاة الفطر **صاع من طعام أهل البلد** — قيمتها النقدية تختلف جذريًا وتُعلنها
جهة رسمية في كل دولة سنويًا. 8 دولارات ليست صحيحة في أي بلد تقريبًا:
مصر تُعلنها بالجنيه، السعودية بالريال حسب قوت البلد، ماليزيا بالرنجيت لكل ولاية،
إندونيسيا بالأرز (2.5 كجم / 3.5 لتر) أو بمقابله نقدًا حسب قرار BAZNAS.

**الحل:** جدول `fitr` داخل الملف الفقهي لكل دولة + رابط المصدر الرسمي + سنة الإعلان،
وواجهة تعرض المصدر صراحة ("حسب إعلان [الجهة] لعام 1447هـ").

### 2.4 🟠 النصاب: قرار فقهي واحد مفروض على العالم كله

```ts
// zakat.ts:67-70
/** Cash nisab uses the lower (silver) — safer for the poor, common fatwa. */
export function cashNisabUSD(p) {
  return Math.min(goldNisabUSD(p), silverNisabUSD(p));
}
```

الاختيار (نصاب الفضة الأقل) **رأي معتبر ومبرَّر**، لكنه **ليس المعمول به في كل الأسواق**:

| السوق | المرجع | نصاب المال المعتمَد |
|---|---|---|
| إندونيسيا | BAZNAS (قرار رئيس BAZNAS، PMA 31/2019) | **85 جرام ذهب** |
| ماليزيا | PPZ / MAIWP وهيئات الولايات | **85 جرام ذهب** (وتختلف تفاصيل الولايات) |
| باكستان | إعلان حكومي/SBP سنويًا | **مبلغ بالروبية يُعلَن رسميًا** (1447هـ ≈ 503,529 روبية) |
| تركيا | الغالب حنفي | **80.18 جرام ذهب** (20 مثقالًا) شائع الاستخدام |
| الخليج / مصر | متنوّع | ذهب 85جم أو فضة 595جم بحسب الفتوى المتّبعة |

فرضُ نصاب الفضة على المستخدم الإندونيسي يجعل نتيجتنا **تخالف مرجعه الرسمي** —
وهو سبب مباشر لفقدان الثقة والانصراف. الحل: `nisabBasis` قابل للاختيار
(`silver` \| `gold` \| `official`) مع **افتراضي لكل دولة** + شرح "لماذا هذا الافتراضي".

### 2.5 🟠 وحدات الوزن: الجرام فقط

المحرك يعمل بالجرام حصريًا (`GOLD_NISAB_G = 85`). لكن:

- **باكستان / الهند:** يفكّر الناس بالـ **تولة** (1 تولة = 11.664 جم) → النصاب 7.5 تولة
- **بنجلاديش:** **بهوري / ভরি** (≈ 11.664 جم)
- **ماليزيا:** **مايام (mayam)** ≈ 3.888 جم للمصوغات
- **الخليج والغرب:** الجرام والأونصة

المستخدم الباكستاني يعرف أنه يملك "10 تولة ذهب"، ولا يعرف وزنها بالجرام.
مطالبته بالتحويل يدويًا = خروج فوري من الصفحة.

### 👤 3) عمر — لندن، بريطانيا · 29 سنة، مهندس (جيل ثانٍ)
**نيّته:** يبحث بالإنجليزية `"zakat calculator uk"`.

**ما يجده:** ❌ **لا شيء.** الموقع لا يظهر له إطلاقًا — لا صفحة إنجليزية، ولا `hreflang="en"`.
ولو وصل بالخطأ، يجد صفحة عربية RTL لا يقرؤها، فيخرج في ثانيتين (bounce 100%).

- **الرهن العقاري (Mortgage):** هل يُخصَم؟ (الجواب الراجح: القسط الحالي فقط) — لا معالجة.
- **قرض الطلاب (Student Loan)** — مسألة كبيرة في بريطانيا.

**النقص المكتشف:** `D-07` نسخة إنجليزية · `D-08` أصول غربية (تقاعد/ISA/401k/كريبتو) · `D-09` معالجة الرهن والقروض

### 👤 4) سيتي نور — كوالالمبور، ماليزيا · 37 سنة، موظفة حكومية
**نيّتها:** `"kalkulator zakat pendapatan"` — **زكاة الدخل الشهرية**.

**ما تجدها:** ❌ الموقع بالعربية، ولا يوجد نوع "زكاة الدخل/الراتب" أصلًا في التبويبات
(هناك **مقالة** عن زكاة الراتب لكن لا حاسبة).

**ما يجعل ماليزيا حالة خاصة تمامًا:**
- **زكاة الدخل تُحسَب شهريًا** لا سنويًا (خصم من الراتب) — نموذج حساب مختلف كليًا.
- **الزكاة في ماليزيا خصم ضريبي (tax rebate) بنسبة 100%** — أي أن كل رنجيت زكاة
  يُخصَم من ضريبة الدخل. هذه ليست معلومة ثانوية: **هي المحرّك الأول للبحث في ماليزيا**.
  أي حاسبة لا تُظهر "أثر الزكاة على ضريبتك" لا تُنافس محليًا.
- **14 ولاية، كل ولاية لها هيئة زكاة وقواعدها وحساباتها** (Selangor/LZS، KL/PPZ-MAIWP،
  Johor، Kedah…). لا بد من اختيار الولاية.
- وحدة **مايام** للذهب، ومصطلحات ملايوية (`nisab`, `haul`, `zakat harta`, `fitrah`).

**النقص المكتشف:** `D-10` زكاة الدخل الشهرية · `D-11` نسخة ملايوية · `D-12` اختيار الولاية · `D-13` حاسبة الأثر الضريبي

> لكن **الأخطر من الاسم هو أنك على نطاق فرعي مجاني.** ترتيب الأولويات:
